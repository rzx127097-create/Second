### 4.5.3 评价指标与统计方法

主要指标：

- 虫害消减率；
- 85% 治理达标率。

协同作业指标：

- 补给请求完成率；
- 请求等待时间；
- 药液失能时间；
- 接驳距离；
- 有效施药时间；
- 实际补给量；
- 车辆行驶距离与库存利用率；
- 平均决策时间。

采用多训练随机种子、共享测试场景、配对差值和分层 bootstrap 进行统计分析。

### 4.5.4 空地协同补给机制有效性验证

设置以下保障模式：

1. 无限药液参考模式；
2. 有限药液且无外部补给；
3. 优化位置的固定保障；
4. Teleport 即时补给诊断上界；
5. 动态需求调度-滚动 A* 移动补给；
6. SR-MAPPO 移动补给。

依次验证药液约束是否真正影响施药、外部补给是否必要、资源瓶颈来自总量不足还是位置-时间错配，以及车辆移动能否缩小固定保障与诊断上界之间的差距。

### 4.5.6 空地协同作用机制分析

从三个层面展开：

1. 空间协同：比较车辆移动前后的接驳距离和道路绕行距离；
2. 时间协同：分析请求生成、车辆到达、服务完成和恢复施药之间的时间关系；
3. 资源协同：分析 UAV 药量、车辆库存、实际转移量和有效施药时间的变化。

重点检验以下机制链：

```text
移动保障
-> 接驳距离缩短
-> 等待与失能减少
-> 有效施药增加
-> 治理效果可能改善
```

### 4.5.7 参数敏感性与场景适应性分析

参数敏感性包括：

1. UAV 初始机载药液比例；
2. 补给车行驶速度；
3. 补给服务时间；
4. 接驳服务半径或请求安全余量。

场景适应性包括：

1. 虫害热点与道路距离变化；
2. 补给需求空间分散程度变化；
3. 多架 UAV 同时请求补给；
4. 道路网络局部阻断。

### 4.5.8 消融实验

- 完整 SR-MAPPO 空地协同方法；
- 无剩余作业时间预测；
- 无车机协同观测；
- 无需求-接驳点联合表征；
- 两阶段训练替代联合训练；
- 同源 MAPPO 配置。

动作掩码、道路约束和服务状态机属于模型合法性条件，不作为消融对象。
